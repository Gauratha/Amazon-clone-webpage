# Amazon Homepage Clone

This is a simple clone of the Amazon website homepage. I built this project to practice writing clean HTML and styling web pages using CSS.

## What's Included

- **Top Navigation Bar**: Amazon logo, search bar, and menu buttons.
- **Main Banner**: Back-to-school promotional banner.
- **Product Cards**: Simple grid boxes showing different categories like gaming, student items, and home goods.

## Built With

- **HTML5**: Page structure.
- **CSS3**: Colors, spacing, and layout.

## How to Run It

1. Download or clone this repository to your computer.
2. Open the `index.html` file in any web browser.
